| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 시작점 | 0 | 0.000 | 0 | 0.00 | | |

기준 전류(µA)는 저항 양단 전압차(V)에 1,000을 곱하고 실측 저항값(kΩ)으로 나눈 값입니다. 시작점의 0 V는 멀티미터 표시값입니다. 시작점과 끝점의 번호 및 게이트 설정은 모드 0의 기본 스윕 조건을 기준으로 적었습니다.

기존 CSV는 별도 스윕 자료입니다. 차이는 반올림 전 기준 전류로 계산했으며, 표시 자릿수는 계측 분해능을 뜻하지 않습니다. [기존 모드 0 CSV](mode-0-transfer.csv)

중간 지점의 실제 게이트 설정과 샘플 번호는 미기록입니다. 기존 CSV에서 멀티미터 기준 전류에 가장 가까운 행은 167번이며, 그 행의 게이트 설정은 0.980431 V, 실측 게이트 전압은 0.98033 V입니다. 상대 차이 0.954%는 이 행과의 참고 차이입니다. 같은 조건의 계측 오차를 확인하려면 게이트 전압을 고정하고 두 계측값을 같은 시점에 기록합니다.
